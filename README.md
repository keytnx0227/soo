# Sumi - SillyTavern 채팅 요약 확장

긴 SillyTavern 채팅을 사용자가 지정한 메시지 ID 범위와 청크 크기에 따라 순차적으로 요약하고, 결과를 현재 채팅에 보관·관리하는 개인용 확장입니다.

현재 버전은 `v0.1.0`입니다. 주요 MVP 기능을 갖추고 실사용 가능한 상태지만, 메시지 ID 안정성처럼 장기 설계가 필요한 부분이 남아 있습니다.

## 주요 기능

### 요약 생성

- 시작·종료 메시지 ID를 직접 지정
- 설정한 청크 크기에 따른 순차 배치 처리
- 이미 요약된 범위와 겹치는 요청 차단
- 최근 요약, 캐릭터·페르소나 정보, World Info, 요약 대상 메시지를 블록 프롬프트로 조립
- 배치 실패 시 실패·완료·미시도 청크 안내

### 요약 기록 관리

- 요약 원문 수정, 삭제, 복사, 재생성
- Google 또는 Bing 기본 번역과 원문·번역문 전환
- 요약별 연속 수정 대화와 최근 수정 대화 복원
- 요약 당시 원본 메시지의 fingerprint 상태 확인
- 레코드 상세 팝업에서 현재 원본 메시지 확인
- ID 높은 순·낮은 순 정렬
- 현재 채팅의 Sumi 요약 데이터 내보내기·가져오기·전체 초기화

### 계층적 압축 요약

- 활성 요약 레코드의 시작점과 연속 레코드 수를 지정해 하나의 압축본 생성
- 원본을 삭제하지 않고 압축본의 직계 자식으로 보존
- 압축본 삭제 시 직계 원본 자동 복원
- 압축본을 다시 묶을 수 있는 단계별 계층 구조
- 사건별 불릿, 감정·관계 궤적, 대표 대사와 압축된 시간·장소 헤더
- 압축 JSON 계약, 출력 템플릿, 블록 프롬프트 프리셋과 전송 미리보기

### 프롬프트와 연결

- 현재 SillyTavern 연결 프로필 그대로 사용
- 현재 프로필의 API 키를 사용하면서 공급자·모델만 별도 지정
- OpenAI, Claude, Google AI Studio, Vertex AI, OpenRouter 지원
- 최대 응답 토큰, Temperature, Top P, Top K 설정
- 추가·수정·삭제·활성화·이동이 가능한 블록형 프롬프트 프리셋
- 실제 전송 프롬프트와 토큰 수 미리보기
- 확장 전역 설정 내보내기·가져오기

### 요약 사용

- `{{sumiSummary}}` 매크로 제공
- 세계 설정을 `{{sumiSummary}}`, 별도 `{{sumiWorldSetting}}` 매크로 또는 World Info 이전·이후로 출력
- 채팅별 세계 설정 직접 추가·수정·삭제
- 채팅 depth 또는 Story/Main Prompt 앞뒤 자동 주입
- 개별 요약 레코드 출력 포맷 설정
- 요약 주입 토큰 예산과 잘린 범위 미리보기
- 최근 채팅의 검색 태그를 바탕으로 장기기억 원본을 자동 회상
- 단순 키워드 일치 또는 관련도 점수 방식, 관련도 상위 N개 제한과 회상 근거 확인
- 장기기억 고정과 검색·토큰 제한 내 최우선 회상
- 요약된 메시지 자동 숨김 및 일괄 숨김·해제

### 현황과 진단

- 전체 메시지 수, 요약된 메시지 수, 마지막 요약 ID 표시
- 요약·미요약 구간을 나타내는 채팅방 현황 맵
- 선택한 구간의 실제 메시지 열람
- 미요약 구간을 요약 범위 입력칸에 바로 적용
- 확장 ON/OFF와 현재 작업 상태 표시
- 미확인 오류 강조 및 세션성 통합 오류 로그

## 설치

이 저장소를 SillyTavern 사용자 확장 경로 아래에 배치합니다.

```text
SillyTavern/data/<user-handle>/extensions/st-chat-summarizer
```

기본 사용자라면 다음 경로를 사용합니다.

```text
SillyTavern/data/default-user/extensions/st-chat-summarizer
```

SillyTavern을 다시 시작하거나 확장을 다시 불러온 뒤, 마법봉 메뉴의 `요약 관리하기`에서 접근할 수 있습니다.

## 기본 사용 흐름

1. `연결 설정`에서 현재 연결 프로필 또는 공급자·모델 별도 지정을 선택합니다.
2. `요약 설정`에서 청크 크기와 사용할 프롬프트 프리셋을 확인합니다.
3. `요약` 탭에 시작·종료 메시지 ID를 입력하고 `요약하기`를 누릅니다.
4. 생성된 결과는 `기록` 탭에서 확인하고 수정·번역·재생성할 수 있습니다.
5. 오래된 활성 요약은 `기록` 탭의 `압축하기`에서 여러 레코드를 하나로 묶을 수 있습니다.
6. `요약 사용 설정`에서 매크로 또는 자동 주입 방식을 선택합니다.

현황 맵의 미요약 구간을 선택한 뒤 `요약 범위로 지정`을 누르면 시작·종료 ID를 직접 입력하지 않아도 됩니다.

## 매크로와 저장 위치

조립된 요약은 다음 매크로로 사용할 수 있습니다.

```text
{{sumiSummary}}
```

확장 설정은 다음 키에 저장됩니다.

```js
extensionSettings.sumi_chat_summarizer
```

채팅별 요약 기록, 도감의 사용자 수정·번역·삭제 상태, 최근 수정 대화는 현재 채팅 메타데이터에 저장됩니다.

```js
chatMetadata.sumi_chat_summarizer
```

`요약 설정` 탭에서 채팅별 요약 데이터와 확장 전역 설정을 각각 내보내고 가져올 수 있습니다. 가져오기는 기존 데이터를 병합하지 않고 같은 범위의 백업 내용으로 교체합니다. 전역 설정을 가져올 때는 현재 확장 켜짐·꺼짐 상태와 채팅별 요약 데이터를 유지합니다. 전체 초기화는 현재 채팅의 요약 데이터만 대상으로 합니다.

오류 로그는 영구 저장하지 않으며 현재 앱 메모리에만 최대 20개 보관합니다. 별도 API 키를 저장하지 않고 SillyTavern 연결 프로필의 키를 사용합니다.

## 설계 원칙

- 프롬프트에 전달되는 내용은 사용자가 확인하고 편집할 수 있는 블록으로 노출합니다.
- 활성화된 블록 이외의 숨은 지시문이나 의미 구분자를 임의로 추가하지 않습니다.
- 일반 요약과 압축본의 명시적인 부모·자식 관계를 저장하고, 장기기억 원본은 최근 문맥의 검색 단서가 일치하거나 사용자가 고정했을 때 조립합니다.
- 확장이 판단하기 어려운 변경을 자동으로 교정하지 않고 상태와 한계를 표시합니다.
- 자동 재시도나 이어하기 대신 실패한 작업 범위를 명확하게 안내합니다.

## 모듈 구조

`index.js`는 manifest에서 불러오는 단일 진입점이며 팝업의 전체 이벤트 흐름을 조율합니다. 기능 모듈은 책임에 따라 다음 디렉터리로 나뉩니다.

```text
connection/   연결 설정 UI와 LLM 요청
core/         설정 저장, 확장 실행 상태, 공통 유틸리티
diagnostics/  세션 오류 상태와 오류 로그 UI
prompts/      프롬프트 조립, 프리셋 편집, 전송 미리보기
records/      요약 기록 목록, 상세 보기, 수정 대화, 현황 맵
summary/      청크 생성, 요약 실행, 레코드 저장, 범위와 원본 추적
translation/  기본 번역 처리
ui/           공통 팝업 골격과 확장 상태 UI
visibility/   요약된 메시지의 자동 숨김 상태 관리
```

현재 단계에서는 진입 흐름을 불필요하게 분산하지 않기 위해 `index.js`를 더 쪼개지 않았습니다. 이후 파일 자체의 책임이 명확하게 나뉠 필요가 생길 때 별도 리팩터링 대상으로 검토합니다.

## 현재 한계

- SillyTavern 메시지 ID는 배열 인덱스이므로 과거 메시지를 삽입·삭제하면 저장 범위가 이동할 수 있습니다.
- fingerprint로 원본 유지·이동·변경 여부를 알리지만 저장 범위를 자동 수정하지는 않습니다.
- 범위 일괄 교정은 내부 삽입처럼 불연속 구간이 생기는 경우를 표현하지 못해 미완성 기능으로 취급합니다.
- LLM 번역과 실제 SillyTavern 메시지 위치로 이동하는 기능은 구현하지 않았습니다.
- 매우 큰 메시지 구간을 상세 보기에서 한꺼번에 열면 성능 저하가 생길 수 있습니다.

## 후속 방향

- 압축 계층의 실사용 결과에 따른 프롬프트와 밀도 조정
- 배열 ID에 덜 의존하는 안정적인 원본 메시지 추적
- 장기 사용 결과에 따른 대규모 채팅 성능 개선
